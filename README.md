# 回卷

一个面向个人使用的读书和观影复习网站。用户可以添加书籍、电影、电视剧等资源；书籍 PDF 可以按页保留原文依据，电影和电视剧可以上传 PDF/TXT 剧本、SRT/VTT/ASS 字幕或 CSV/XLSX 台词表，并在台词校对后生成经典台词和角色专题试卷。系统继续支持单选题、多选题和问答题，在提交后给出自动评分、参考答案和可追溯的资料依据；没有可信资料时，也可以只填写标题和主创信息，使用真实模型的内化知识兜底出题。精确台词题不会使用模型记忆兜底，模型返回的台词、角色和来源必须通过后端校验。系统会保存生成好的复习试卷；同一套试卷可以反复作答，每次作答单独记录为一个复习任务。

出题时系统按“事实”去重，而不是只比较题干文字：模型需要返回被考察的标准事实，后端会结合主体、关系、情节范围和答案事实值识别不同问法下的同一题，并在发现重复时自动重出。去重范围同时覆盖本套试卷和同一资源的历史试卷；旧题会通过数据迁移补齐事实签名，手工改题后也会重新计算。资料不足以支撑足够多独立事实时，任务会明确失败并提示降低题量或扩大范围。

当前版本默认使用 Mock AI Provider，也可以在“模型设置”页面切换到 OpenAI 兼容模型。综合内容模式会优先使用已解析 PDF 与已确认可信台词的综合来源；只有两者都没有时，真实模式才使用模型知识兜底。Mock 模式不支持无来源的模型知识出题，客观题始终由后端按标准答案确定性评分。

## 技术栈

- 网页端：Next.js、React、TypeScript、Tailwind CSS
- 后端：FastAPI、Python 3.12、SQLAlchemy、Alembic
- 数据：SQLite、本地文件存储、PyMuPDF、openpyxl
- 测试：pytest、Playwright

考试分享第一版已经可用：用户可以从资源详情中的已完成试卷生成带有效期的公开考试链接，在“考试管理”查看参与统计、逐份答卷，并通过编辑入口按版本修改题目、单题重出和删除历史版本；管理员可以在“系统管理 / 考试管理”查看全平台考试。参与者支持平台账号、微信认证和匿名名称三种身份，重新打开链接时可按对应身份找回历史答卷。已开始或已完成的答卷会冻结各自开始时的考试快照，不受后续改题影响。公开接口在交卷前隐藏答案与解析，并始终隐藏 PDF 文件名、页码和原文摘录；问答题异步评分失败后可由分享者或管理员重新评分。

## 本地开发

项目使用 Conda 环境 `read-books`。首次安装：

```bash
conda env create -f environment.yml
npm --prefix apps/web install
conda run -n read-books alembic -c apps/api/alembic.ini upgrade head
```

如果环境已经存在，可以使用：

```bash
make setup
```

同时启动前后端：

```bash
make dev
```

- 网页端：<http://localhost:3000>
- API：<http://localhost:8000>
- OpenAPI：<http://localhost:8000/docs>

也可以分别运行 `make dev-web` 和 `make dev-api`。

## 配置

复制根目录 `.env.example` 为 `.env` 后按需修改。开发阶段默认：

```env
MOCK_MODE=true
SEED_DEMO_DATA=true
```

当项目根目录存在 PDF 时，开发启动会自动建立对应书籍并后台解析；如果 PDF 原生文字是乱码或受到复制权限限制，会在 macOS 上自动调用 Vision OCR 兜底。原文片段仍然保留 PDF 页码。本地 PDF、SQLite 数据库和上传目录均不会提交到 Git。

网页端的“模型设置”页面（`/settings/model`）已经支持保存接口地址、模型名称、API Key、请求超时和温度，并通过一个开关选择已配置模型或内部模拟接口。配置保存在本地 SQLite 中，API Key 只在保存时写入，读取接口不会返回明文；页面以固定 16 位掩码显示已配置状态，输入新值并保存即可覆盖更新。页面还可以发送最小 OpenAI 兼容请求测试连接，并展示脱敏后的等价 `curl` 命令和模型实际返回文本。环境变量 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`、`LLM_TIMEOUT_MS` 和 `LLM_TEMPERATURE` 仍作为尚未在网页端保存配置时的默认值。

资料理解层用于降低出题时“捏造事实”的风险：PDF/台词等资料解析完成后，系统会在后台自动按集数或页码窗口增量生成摘要（内容未变化的分组直接复用旧摘要），并为原文片段生成向量用于语义召回；出题时用向量相似度替代随机抽样挑选候选原文，同时把摘要作为“背景理解”注入 Prompt 帮助模型把握上下文，但摘要本身不会成为可引用来源，题目仍然只能引用原文片段的真实 ID。生成的题目在通过来源 ID、角色归属和精确出处禁问等硬校验后，还会经过分级忠实性校验：极低词面重合度才拒绝，中间区间记录 warning，允许合理的语义转述。出题过程中可以复制整套当前 Prompt、模型回复、题目草稿和 Token；可以终止任务，保留中间结果后再删除任务及调试记录。检测失败的题目会自动回填最近一次模型返回的题干、选项、答案、解析和知识点，已生成题目也能在任务完成前人工调整。相关设计详见 `docs/material-understanding-design.md`。该功能依赖新增的环境变量 `LLM_EMBEDDING_MODEL`（向量模型名称，留空则不生成向量、出题召回自动回退为随机排序）、`LLM_EMBEDDING_TIMEOUT_MS`（向量请求超时，默认 `60000`）和 `MATERIAL_UNDERSTANDING_ENABLED`（默认 `true`，关闭后不生成摘要和向量，出题仍按原有随机排序进行）。

“系统管理”下新增“备案设置”（`/settings/site`），管理员可以填写备案号和备案号链接；保存后会自动更新到网站底部，留空两项并保存可移除展示。

资源详情页新增“可信资料”区域，支持上传剧本、字幕和结构化台词表并查看逐文件解析状态；待校对资料可以进入 `/books/{bookId}/quotes` 修正角色、上下文以及是否用于出题。生成试卷页提供“综合内容 / 经典台词 / 角色专题”三种主题，专题模式可以选择资料、角色和考察角度。资料解析和专题出题都在后台执行；删除资料不会删除已经生成的试卷和考试快照，但依赖该资料的题目将不能自动重出。

“系统管理”下的“微信登录”页面旁新增了自检页（`/settings/wechat/test`），会按“读取配置 -> 诊断登录 -> 回调落库 -> `/api/public/wechat/me` -> 退出会话”分步展示后台逻辑，并给出可复制的 `curl` 命令；诊断链路不依赖正式开关，不需要先把公开考试微信登录打开。

切换到 OpenAI 兼容模式后，新测试会调用配置地址的 `/chat/completions` 生成题目，提交测试时的问答题也会调用同一模型评分。PDF 模式下模型只能引用后端提供的原文片段 ID，文件名、页码和原文摘录由后端从数据库重建；模型知识模式下来源片段 ID 和原文依据必须为空，系统不会采信或保存模型伪造的页码、文件名和引文。题量、题型、选项、答案、参考答案和评分要点均会经过结构校验，接口不可用或返回内容不合规时不会保存不可靠题目。

出题采用持久化后台任务：创建接口立即返回，网页端显示已完成题数和当前阶段，用户可以在生成期间访问其他页面。同一套试卷的多道题按顺序逐题请求模型，每次只要求生成一道题，并缩小候选原文范围，以降低长响应超时和无效 Token 消耗。实际出题和问答评分请求不主动设置 `max_tokens`，由模型服务按自身能力和上下文窗口决定输出；同时兼容文本片段数组形式的响应。如果模型只返回推理过程或触发模型服务自身输出上限，任务会保留明确失败原因。任务失败会保留已完成题数和错误信息；服务重启后会恢复未完成任务。

“系统管理”下的“提示词管理”页面（`/settings/prompts`）支持调整出题和问答评分两套模板；“Token 用量”页面（`/settings/token-usage`）支持按任务和阶段查看模型调用的输入、输出 Token、耗时和失败信息。出题模板支持资源名称、主创信息、资源类型和来源模式变量，管理员修改提示词不能绕过后端的题目结构与来源校验。资源详情页展示后台预生成测试的任务状态，生成完成的试卷会进入下方试卷列表；无 PDF 时需要先启用已配置的真实模型，已有但尚未解析完成的 PDF 不会自动降级为模型知识模式。

预生成的运行状态属于具体资源：后台策略只为符合条件的资源准备题目，资源详情页展示进度和结果，完成后统一从试卷列表进入。默认题型、题量、目标时长、并发上限等属于系统策略，后续开放多租户时建议采用“平台默认值 -> 租户覆盖 -> 资源局部覆盖”的配置层级；任务记录则独立保存，便于管理员按租户查看用量和失败情况。当前本地版使用进程内后台线程，公网部署前应替换为独立任务队列和 Worker。

资源详情页的试卷列表会展示难度（基础、适中、深入）、总题数、单选/多选/问答题数量、复习次数和最近成绩。删除试卷前页面会二次确认；删除会级联清理该试卷的题目、复习任务和答案，同时解除预生成及出题任务的结果引用，但保留模型 Token 用量记录用于审计。

全局“复习记录”页面支持按资源名称或主创搜索（输入完成后按回车提交），也支持按任务状态筛选，并提供查看、继续、重新答题和删除操作。

书架页面的书名和作者搜索同样在输入完成并按下回车后才更新列表，输入过程中不会重复请求后端。

网页展示的任务、试卷、复习、模型测试、提示词版本和 Token 调用时间统一使用北京时间（`Asia/Shanghai`），格式为 `YYYY-MM-DD HH:MM:SS`；后端内部仍统一按 UTC 记录，便于未来多时区部署。

没有已解析 PDF 且没有已确认可信台词时，系统会将试卷标记为“模型知识模式”，并在书籍、出题、试卷、答题和结果页面持续提示：题目不具备可靠的 PDF 页码或逐句原文依据，可能受版本差异和模型记忆偏差影响。需要可追溯复习时应上传并完成解析 PDF 或可信台词资料；PDF 模式的原文依据会高亮与当前题目最相关的关键句。未来可通过独立的图书元数据 Provider 对接豆瓣等服务进行版本检索，但版本元数据不能替代正文依据。

OCR 配置为 `OCR_ENABLED` 和 `OCR_COMMAND`。当前 OCR 脚本使用 macOS Vision，适合本地开发；其他操作系统若没有对应命令，解析会失败并阻止无依据出题。

## 远程部署

项目已提供统一的生产服务脚本和远程部署脚本。部署到当前服务器：

```bash
scripts/deploy.sh
```

远端服务统一通过以下命令管理：

```bash
cd /home/mengalong/website/read-books
scripts/server.sh start
scripts/server.sh stop
scripts/server.sh restart
scripts/server.sh status
scripts/server.sh logs
```

完整端口、Nginx、生产配置和 HTTPS 注意事项见 [远程部署文档](docs/deployment.md)。如果域名能跳转但公网 HTTPS 仍打不开，优先检查云厂商是否放行了 `443/TCP`，再核对 Nginx 证书和本机 443 监听状态。
