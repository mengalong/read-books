# 回卷开发状态

更新日期：2026-08-02

## 当前阶段

首版 MVP 开发中。后端核心业务和 OpenAI 兼容模型链路已完成并通过自动化测试，网页端完整页面已实现，乱码 PDF 的 OCR 兜底和基础响应式布局已完成本地联调。

## 已完成

- 确认单用户、中文优先、桌面网页优先的产品范围。
- 建立 `read-books` Conda 环境，使用 Python 3.12。
- 建立 FastAPI 应用、统一环境配置、CORS 和健康检查。
- 建立 SQLite、SQLAlchemy 数据模型和首个 Alembic 迁移。
- 实现书籍新增、查询、编辑和删除接口。
- 实现 PDF 流式上传、后台解析、失败反馈和中断恢复。
- 使用 PyMuPDF 按页抽取文字，并保存 PDF 文件名、页码和原文片段。
- 检测 PDF 字体编码乱码；在 macOS 开发环境使用 Vision OCR 按页恢复中文。
- 实现 Mock AI Provider 与真实 OpenAI 兼容 HTTP Provider 的统一配置边界。
- 增加网页端“模型设置”页面，支持接口地址、模型名称、API Key、超时和温度配置，并用一个开关控制内部模拟接口或已配置模型。
- 将模型配置持久化到 SQLite；API Key 只返回是否已配置，页面用固定 16 位掩码显示并支持输入新值覆盖更新。
- 增加模型配置接口校验、OpenAI 兼容连接测试、脱敏 curl 命令、模型实际返回展示和最近一次链接状态持久化。
- 接入真实模型出题和问答题评分；严格校验结构化输出，并根据数据库原文片段重建文件名、页码和原文依据。
- 增加提示词管理页面，支持出题和问答评分模板的变量校验、替换预览、版本保存和恢复默认。
- 增加书籍后台预生成测试，支持 pending、processing、completed、failed 状态，前端轮询展示并由后端防止重复触发。
- 将真实模型默认请求超时调整为 180 秒，并对读取超时返回可操作的中文提示；出题候选片段数量收紧，降低长请求超时概率。
- 实现单选题、多选题、问答题生成，默认题量为 5、3、2。
- 实现近期来源片段降权，连续测试优先覆盖不同原文。
- 实现客观题确定性评分、问答题模拟或真实模型评分、参考答案和评分要点。
- 实现测试历史、薄弱知识点和下次建议复习日期。
- 完成书架、书籍详情、测试配置、答题、结果和历史页面。
- 后端自动化测试覆盖完整复习流程。
- 通过 TypeScript 检查和 Next.js 生产构建。
- 使用《红楼梦》完成书籍详情、出题、答题、自动评分和结果页浏览器联调。

## 本地验证数据

项目根目录中的《红楼梦》PDF 已确认需要 OCR 兜底，并已完成重新解析：

- 文件：`红楼梦脂评汇校本 v3.14.pdf`
- 页数：1042 页
- 原生解析：失败（PDF 禁止复制文字，且正文编码无法可靠还原）
- 可读性检查：1042 页中只有 7 页达到可读中文阈值
- OCR 方案：macOS Vision，输出保留原 PDF 页码
- 解析状态：完成
- 原文片段：1042 个

OCR 结果通过最低文字量检查后，系统会用 OCR 片段生成测试；如果 OCR 失败，系统会保留书籍和 PDF 记录但禁止出题。PDF 仅作为本地开发数据使用，已通过 `.gitignore` 排除，不进入版本库。
