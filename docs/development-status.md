# 回卷开发状态

更新日期：2026-08-03

## 当前阶段

首版 MVP 核心闭环已完成。后端、OpenAI 兼容模型链路、异步出题、试卷复用、试卷管理和复习任务管理已经通过自动化测试；网页端完整页面、乱码 PDF 的 OCR 兜底和响应式布局已完成本地联调。

## 已完成

- 确认单用户、中文优先、桌面网页优先的产品范围。
- 建立 `read-books` Conda 环境，使用 Python 3.12。
- 建立 FastAPI 应用、统一环境配置、CORS 和健康检查。
- 建立 SQLite、SQLAlchemy 数据模型和首个 Alembic 迁移。
- 实现书籍新增、查询、编辑和删除接口。
- 实现 PDF 流式上传、后台解析、失败反馈和中断恢复。
- 使用 PyMuPDF 按页抽取文字，并保存 PDF 文件名、页码和原文片段。
- 检测 PDF 字体编码乱码；在 macOS 开发环境使用 Vision OCR 按页恢复中文。
- 实现 Mock AI Provider 与真实 OpenAI 兼容 HTTP Provider 的统一配置边界。
- 增加网页端“模型设置”页面，支持接口地址、模型名称、API Key、超时和温度配置，并用一个开关控制内部模拟接口或已配置模型。
- 将模型配置持久化到 SQLite；API Key 只返回是否已配置，页面用固定 16 位掩码显示并支持输入新值覆盖更新。
- 增加模型配置接口校验、OpenAI 兼容连接测试、脱敏 curl 命令、模型实际返回展示和最近一次链接状态持久化。
- 接入真实模型出题和问答题评分；严格校验结构化输出，并根据数据库原文片段重建文件名、页码和原文依据；对常见字段别名、缺失的可推导字段和一次格式修正重试做了兼容。
- 增加 PDF 原文与模型知识两种出题来源模式；没有 PDF 时，真实模型可以根据书名、作者和内化知识出题，题目不保存任何伪造的页码、文件名或原文依据。
- 为试卷和出题任务增加来源模式字段并完成数据库迁移；模型知识模式在书籍、出题、试卷、答题和结果页面显示版本差异、记忆偏差及无 PDF 原文依据提醒。
- 增加提示词管理页面，支持出题和问答评分模板的变量校验、替换预览、版本保存和恢复默认。
- 增加书籍后台预生成测试，支持 pending、processing、completed、failed 状态，前端轮询展示、后端防止重复触发，并在服务重启后恢复未完成任务。
- 将手动出题和预生成统一为持久化异步任务，接口立即返回；前端展示总题数、已完成题数和当前阶段，生成期间可以继续访问其他页面。
- 将整套模型请求拆为逐题请求，每次只生成一道题并收紧候选原文范围，降低真实模型长响应超时和输入 Token 消耗；服务重启后恢复手动与预生成任务。
- 针对推理型 OpenAI 兼容模型，实际出题和问答评分不主动设置 `max_tokens`，并兼容文本片段数组；模型只返回推理内容或触发模型服务自身输出上限时记录具体失败原因。
- 增加系统管理下的 Token 用量统计，按任务和模型调用阶段记录输入、输出、总 Token、耗时和失败信息；真实接口未返回 usage 时标记为未报告。
- 预生成的开启和运行状态按书籍维护；有 PDF 的书籍或已启用真实模型的无 PDF 书籍均可预生成，预生成默认题型、题量和资源限制保留为系统/未来租户策略边界，后续支持平台默认、租户覆盖和书籍覆盖的配置层级。

## 本地验证数据

项目根目录中的《红楼梦》PDF 已确认需要 OCR 兜底，并已完成重新解析：

- 文件：`红楼梦脂评汇校本 v3.14.pdf`
- 页数：1042 页
- 原生解析：失败（PDF 禁止复制文字，且正文编码无法可靠还原）
- 可读性检查：1042 页中只有 7 页达到可读中文阈值
- OCR 方案：macOS Vision，输出保留原 PDF 页码
- 解析状态：完成
- 原文片段：1042 个

OCR 结果通过最低文字量检查后，系统会用 OCR 片段生成测试；如果 OCR 失败，系统会保留书籍和 PDF 记录但禁止出题。PDF 仅作为本地开发数据使用，已通过 `.gitignore` 排除，不进入版本库。
