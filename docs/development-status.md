# 回卷开发状态

更新日期：2026-08-20

## 当前阶段

首版 MVP 核心闭环、多用户第一阶段、考试分享第一版和资源类型扩展已完成。当前支持管理员与普通用户登录、个人工作空间隔离、管理员系统管理、跨用户资源管理、用户访问统计，以及面向平台账号、微信身份或匿名参与者的试卷分享、公开答题、历史答卷找回和异步评分；系统已通过域名提供 HTTP 到 HTTPS 的跳转支持，远端本机 HTTPS 已可用，但公网可达性仍取决于云厂商是否放行 `443/TCP`。后端测试、TypeScript 检查、生产构建和关键 Playwright 流程持续作为发布前基线。微信正式登录还依赖微信开放平台网站应用和 HTTPS；公开接口限流、生产数据库、持久化任务队列和对象存储完成前，当前环境不作为正式公网发布版本。

## 本地验证数据

项目根目录中的《红楼梦》PDF 已确认需要 OCR 兜底，并已完成重新解析：

- 文件：`红楼梦脂评汇校本 v3.14.pdf`
- 页数：1042 页
- 原生解析：失败（PDF 禁止复制文字，且正文编码无法可靠还原）
- 可读性检查：1042 页中只有 7 页达到可读中文阈值
- OCR 方案：macOS Vision，输出保留原 PDF 页码
- 解析状态：完成

OCR 结果通过最低文字量检查后，系统会用 OCR 片段生成测试；如果 OCR 失败，系统会保留书籍和 PDF 记录但禁止出题。PDF 仅作为本地开发数据使用，已通过 `.gitignore` 排除，不进入版本库。
